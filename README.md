# School ERP Backend

## Tech Stack
- Node.js + Express
- PostgreSQL
- JWT Authentication
- Role-Based Access Control

## Setup
1. Clone repo
2. Copy `.env.example` → `.env`
3. Install dependencies
   npm install
4. Run server
   npm run dev

## Modules Implemented
- School & Role Setup
- Academics
- Teachers & Students
- Attendance & Marks
- Admissions → Enrollment (FINAL)

⚠️ Enrollment uses a single flow: generateEnrollment
